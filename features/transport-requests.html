Transport Requests

Turn each requisition into approved, sourced shipments

Distribution splits a finished-goods requisition across the sites that will supply it, and the Distribution Manager approves it. Procurement breaks each port shipment down by destination. Every request then reaches Transport's planning queue with its remarks attached.

What you get

One controlled step between demand and transport

Split by source site

One requisition can be supplied from several depots or feed mills, one transport request each, never more than was requested.

Manager approval

The Distribution Manager approves, adjusts with remarks or rejects each finished-goods request before Transport sees it.

Port breakdown by destination

Procurement divides each import across receiving sites, and the requests go straight to transport planning.

Distribution

Decide which site supplies what

The Distribution Officer opens a submitted finished-goods requisition and creates a transport request for each source site.

  • Pick the source site for each request; the destination comes from the requisition and can't be the same site
  • Enter the quantity per product line, with the amount still left shown as you type
  • Quantities above what is left are blocked; the rest can go in later requests
  • Each request is numbered automatically, for example TR-FG-20261014-0019, and goes straight to approval

Approval

Approve, adjust or send back

The Distribution Manager works from one queue of requests waiting for approval, filtered by delivery date, urgency and status.

  • Approve as it is, or change quantities and the delivery date first, with remarks required
  • Reject with a reason, and the request goes back to the Distribution Officer
  • Approve or reject several requests at once from the list
  • Every decision is recorded with who made it, when, and the remarks

Port shipments

Break each import down by destination

The Procurement Officer plans where raw material goes, straight from the port shipment the commercial team registered.

  • The source opens on the shipment's goods pickup location, and any other active site can be chosen
  • One request per destination site, which must differ from the source
  • Quantities per raw-material line, never more than is left on the shipment
  • No approval step: each request is available for transport planning as soon as it is submitted

Handover to Transport

Ready for planning, with nothing lost on the way

Approved finished-goods requests and submitted port requests appear together in the Transport Planner's queue.

  • The planner sets the vehicle type and the number of vehicles, plus a C&F clearance note for port loads
  • The request moves to Under planning, and only then can transport orders be created
  • Its status follows the orders: Partially allocated, Fully allocated, then Assigned
  • Remarks from the creator and the manager are shown when the planner creates a transport order

Who uses it

Each team sees its own part

Distribution

Officers create requests from finished-goods requisitions; the manager reviews and decides on every one.

Procurement

Creates the destination breakdown for each port shipment, one request per receiving site.

Transport planning

Receives every request that is ready, adds the vehicle plan and turns it into transport orders.
